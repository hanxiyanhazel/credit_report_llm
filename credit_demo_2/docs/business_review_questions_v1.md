# 需要业务核对的问题清单（V1）

这份清单用于沉淀 **“技术上能查，但业务口径需要确认”** 的问题。  
后续 SQL 版、metric 版都应优先参考这份文档，避免一边开发一边反复改口径。

## 1. 未结清账户数/余额/相关负债

需要核对点：

- “当前未结清账户”是否只指 `授信及负债信息概要` 中的未结清/未销户账户。
- “相关还款责任”是否默认排除在主口径之外，只作为扩展口径补充。
- “被追偿信息”是否计入“当前负债余额”主口径。

当前建议：

- 主口径：`未结清/未销户账户`
- 扩展口径：`含相关还款责任的相关负债`

## 2. 借款金额 / 余额 / 授信额度 / 债权金额

需要核对点：

- “借款金额”是否仅统计明确有借款金额字段的贷款账户。
- 循环贷账户的 `账户授信额度` 是否允许并入“借款金额/授信金额”扩展口径。
- 被追偿的 `债权金额` 是否永远不能并入“借款金额”。

当前建议：

- `借款金额` 主口径与 `余额` 主口径分离。
- 如需把循环贷账户并入，应在回答中明确写成“借款金额/授信金额口径”。

## 3. 逾期账户数 / 逾期记录数 / 最多连续逾期期数

需要核对点：

- “逾期账户有多少”是否按 `COUNT(DISTINCT account_id)`。
- “逾期记录多少条”是否按 `账户-月份` 粒度统计。
- “最多连续逾期期数”默认取 `状态最大值口径` 还是 `自然月连续段口径`。

当前建议：

- 默认：
  - 账户数 = 去重账户数
  - 记录数 = 账户-月份记录数
  - 最多连续逾期期数 = 状态最大值口径
- 自然月连续段只做补充，不替代主口径。

当前系统回答建议：

- 如果用户问“逾期账户有多少”，当前系统应至少明确：
  - 返回的是 `发生过逾期的去重账户数`
  - 不是 `账户-月份口径的逾期记录数`
- 如果业务允许并列展示，建议进一步补一句：
  - “如按账户-月份口径统计普通逾期记录数，结果会不同，需单独查询或并列展示。”

## 4. 查询次数：概要口径 vs 明细口径

需要核对点：

- “近1个月查询次数”默认是 `PC05 概要` 还是 `PH01 明细回算`。
- “本人查询”是否只在概要口径中统计，不要求明细补齐。
- “近3个月/近6个月/近1年”是否默认按明细口径。

当前建议：

- 报告已有固定概要窗口：优先概要
- 自定义窗口：优先明细
- 若涉及本人查询，需显式提示是否仅为概要口径

## 5. 五级分类异常范围

需要核对点：

- 默认是否只统计本人名下信贷账户。
- 相关还款责任账户中的非正常五级分类是否单列，不并入主结论。

当前建议：

- 主口径：本人名下信贷账户
- 扩展口径：相关还款责任账户异常单列展示

## 6. 信用卡个性化分期 / 展期 / 大额专项分期

需要核对点：

- “大额专项分期”是否只提示为分期类业务，不视为负面事件。
- 只有明确出现“个性化分期”“展期”“协商还款”等字样时，才判断命中。

当前建议：

- 大额专项分期 != 个性化分期/展期
- 默认不要混写

## 7. 地址同省市判断

需要核对点：

- 地址脱敏、缺省、或单位地址不是标准地址时，是否统一返回“无法判断”。

当前建议：

- 只在能稳定解析省市时判断
- 其余情况不强猜

## 8. 需要继续补充的业务问题

后续如遇到以下情况，也应追加到本清单：

- 一个问题存在两个以上可接受口径
- SQL 可算，但业务意义不唯一
- 追问依赖上一轮结果集，口径角色容易漂移
