# 个人报告计算口径基线 V1（Single Source of Truth）

本文件用于固定“问题 -> 主口径 -> 备用口径 -> 冲突处理”，是当前实现与回归的唯一基线。

## 1. 全局规则

1. 先结构化，再计算，再解释；禁止直接让大模型按 PDF 自由算账。  
2. 所有统计必须带 `report_id`，时间窗以 `report_basic.report_time` 为基准。  
3. 强制区分：
   - `借款金额`
   - `余额/已用额度/透支余额`
   - `授信总额`
4. 概要与明细冲突时不硬合并：返回双值与 `delta`，并标记 `partially_answerable`。

## 2. 七类需求主口径

### 2.1 逾期情况

- 主口径：`account_history`（账户-月份明细）。  
- 逾期判定：`repay_type in 1..7` 或 `overdue_total > 0` 或 `overdue_months > 0`。  
- 连续逾期：同账户按月份连续（相差 1 个月）计算最长连续段。  
- 备注：`B/D/G/*/#/N/C` 不并入普通 1-7 逾期次数。

### 2.2 授信情况（贷款+卡）

- 当前未结清账户数/余额主口径（PC02 概要）：
  - 账户数：`PC02BS01 + PC02ES02 + PC02FS02 + PC02GS02 + PC02HS02 + PC02IS02`
  - 余额：`PC02BJ01 + PC02EJ02 + PC02FJ02 + PC02GJ02 + PC02HJ04 + PC02IJ04`
- “相关还款责任”扩展口径：
  - 账户数 + `sum(PC02KS02)`
  - 余额 + `sum(PC02KJ02)`
- 未结清贷款借款金额口径（明细字段）：
  - 表：`credit_account.original_amount`
  - 范围：`非循环贷账户 + 循环额度下分账户`
  - 条件：`close_date` 为空
  - 金额汇总剔除 `呆账/核销`

### 2.3 个人身份信息

- 主口径：`PB01/PB03/PB04` 结构化字段。  
- 地址同省市判断：省市缺失或脱敏时返回“无法判断”，禁止猜测。  
- 单位风险词：词表匹配（地产/投资/担保/小贷/融资租赁等）。

### 2.4 查询情况

- 明细口径：`query_record(PH01)`，用于 1/3/6/12/24 月窗口自定义统计。  
- 概要口径：`PC05`，用于“最近1个月/最近2年”固定展示项。  
- 对账规则：
  - 可比项按 reason 子集对账（贷款审批/信用卡审批/贷后管理/担保资格审查/特约商户实名审查）。
  - 不可比项（如本人查询未逐笔落地）只提示，不强行回算。

### 2.5 五级分类

- 主口径：`credit_account.five_classification`。  
- 异常集合：`关注/次级/可疑/损失`。  
- 输出区分“当前异常”和“历史曾异常（如后续补齐历史轨迹）”。

### 2.6 担保情况

- 主口径：`guarantee_record + PC02K 概要`。  
- 不把“本人贷款担保方式”混入“本人对外担保责任”。  
- 对外担保关注：金额、余额、业务种类、是否逾期/五级分类异常。

### 2.7 异议情况

- 总笔数主口径：`PG010S01`（概要）。  
- 明细辅助：`objection_record(POS)` 仅用于定位与解释，不替代概要总笔数。  
- 明细分类：
  - `objection_candidate`
  - `information_missing_annotation`
  - `other_annotation`

## 3. 冲突处理标准

1. 可比指标 `abs(delta) > 0`：`verifier_status=partially_answerable`。  
2. 回答必须带：
   - 主口径结果
   - 对账结果（summary/detail/delta）
   - 冲突原因代码（如 `query_scope_mismatch_pc05_vs_ph01`）。
3. 无可比字段时：返回 `not_comparable`，并明确“不可比原因”。

## 4. 回归验收最小集（必须长期维护）

1. 当前未结清账户有多少个？  
2. 当前未结清账户余额合计是多少？  
3. 当前未结清贷款借款金额合计是多少？  
4. 近6个月查询次数和原因分布是什么？  
5. 最近1个月查询次数（概要）是多少？  
6. 近1年、近2年逾期次数和最长连续逾期期数是多少？  
7. 是否有在途异议？概要和明细各是多少？
